Atualização automática pelo JSON

O painel lê demandas.json publicado junto desta página e verifica atualizações a cada cinco minutos. Um fluxo autorizado deve gerar esse JSON a partir das abas activities e logs da planilha.

Privacidade: arquivos no GitHub Pages público podem ser lidos por qualquer pessoa, inclusive o JSON. Não publique nele dados internos/confidenciais; para isso, o destino do JSON e o painel precisam de controle de acesso corporativo.

Formato esperado para demandas.json

O processo que exportar a planilha deve criar um objeto com schemaVersion igual a 1, generatedAt em data/hora ISO 8601 e demands como lista. Cada demanda tem id, title, category, type e logs; cada evento contém action, status e date. O evento mais recente determina o status exibido.

{
  "schemaVersion": 1,
  "generatedAt": "2026-10-02T20:00:00Z",
  "demands": [{
    "id": "6219",
    "title": "Exemplo de título",
    "category": "Categoria",
    "type": "Melhoria",
    "logs": [
      { "action": "Cadastrar", "status": "Não Iniciado", "date": "2026-10-01T12:00:00Z" }
    ]
  }]
}
